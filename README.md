# NapCat QQ for VS Code

基于 NapCat / OneBot v11 的 VS Code 桌面聊天插件。聊天记录和底部草稿位于同一个原生编辑器，使用当前 VS Code 的字体、行号、主题配色、文本选择、查找和分屏。

## 使用

1. 启动 NapCat，在网络配置中启用 **OneBot v11 正向 WebSocket 服务**。默认地址是 `ws://127.0.0.1:3001`。
2. 打开 VS Code 左侧 **QQ** 图标。插件默认在打开 QQ 视图时自动连接。
3. 如需调整连接，运行 `QQ: 连接设置`。也可以运行 `QQ: 导入 tuiqq 配置`，选择参考项目的 `config.json`。Token 保存到 VS Code SecretStorage。
4. 在上下排列的“列表 / 收藏”两个列表中选择会话，在文档底部的 **草稿** 分隔线下面直接输入。
5. **Enter 发送，Shift+Enter 或 Ctrl+Enter 换行**（macOS 为 Cmd+Enter）。这些快捷键仅在草稿区生效，输入法组合输入期间不触发发送。
6. 编辑器右上角 **图片** 导入图片，**表情** 打开 QQ 表情选择器。选择图片或表情后，在草稿光标处插入占位符。
7. 在草稿输入 `/`，使用原生补全选择 `/表情`（或 `/emoji`），Enter 打开底部选择器。方向键选择表情，Enter 插入占位符、自动收起底部面板并返回草稿，Esc 取消；选择器不会直接发送消息。也可继续使用工具栏“表情”按钮。收藏表情支持动图预览，加载失败的格子可点击重试。

## 功能

- 两个列表均有搜索按钮。输入名称或号码即时筛选，支持空格分隔多个关键词；Enter 保留搜索，Esc 取消，标题 × 清除。命令 `QQ: 搜索会话` 可跨列表快速打开。
- 收藏 / 取消收藏、未读计数、`@我` / `回复我` 标记。群聊普通未读只列入 QQ 设置为“接收并提醒”的会话；免打扰等群的普通消息过滤，但 `@我`（含全体成员）和回复自己的消息例外进入未读并提示。手动“忽略未读”的会话仍全部静默。
- 群提醒设置通过 `get_group_detail_info.cmdUinMsgMask` 同步，最多 4 个并发，成功缓存 5 分钟；点列表刷新按钮可立即重新读取。好友接口不返回 QQ 免打扰状态，好友暂按普通消息计入，可右键“忽略 / 恢复此会话未读”。这个操作只影响插件本地列表。
- 群聊和好友历史、实时消息、断线自动重连、每个会话独立草稿。
- 在消息上右键回复、复制消息原文；Ctrl+Shift+R 回复光标所在消息。
- 默认只显示文本；图片显示高亮 `[图片]`，悬浮预览在 **240×160** 范围内等比例缩小，并根据编辑器可见高度进一步缩小，给悬浮窗文字和按钮留出空间，小图不放大。按 VS Code 的打开链接手势（通常 Ctrl+单击）或悬浮窗中的“打开大图”进入内置图片预览，可使用内置缩放功能。
- 草稿支持导入图片和粘贴剪贴板图片，以 `[图片:1]`、`[表情:2]` 等占位符显示。发送时按它们在文字中的位置转换成消息段，不会把占位符发成文字。删除占位符即不发送该附件；重复占位符会重复发送；失去附件映射的标记会阻止发送并提示重新导入。
- **表情** 面板默认打开收藏表情，另有“最近使用”和“QQ 表情”页签。最近使用按插入顺序去重排列，最多 10 个，按账号保存；收藏表情副本保存在本地，重新打开仍可预览。收藏表情通过 NapCat `fetch_custom_face` 读取，按需加载缩略图，可刷新和加载更多。
- 支持纯图片、纯表情，以及文字和附件一起发送。收藏表情按图片表情发送，GIF 保持原文件。
- 图片和附件通过插件缓存处理，发送时使用 OneBot 图片消息段；支持 NapCat 在另一台机器运行，不要求它访问编辑器的本地文件路径。

引用、昵称和正文使用专用 `qq-chat` 语言及 C 风格 TextMate 作用域，例如：

```c
#define CHAT_NAME "开发群"
#define GROUP_ID "123456"
#define INFO "调试员" "群名片" "12:30:01"
// 备注：好友备注
void recv_10001(void) {  // 管理员
    char msg[] = "消息内容[图片]";  // [回复]
}

#define INFO "" "我的名片" "12:30:05"
void send_reply_123456(void) {  // 我
    char replay[] = "群名片：消息内容[图片]";
    char msg[] = "收到";  // [回复]
}  // ✓ 已发送
```

自己的消息有 `send`、函数行注释中的 `我` 标签以及当前主题的新增行底色/边线，其他人为 `recv`。群聊名称取 `group_name`；群成员优先群名片，其次昵称；群内好友以独立注释显示不同的好友备注及昵称；显示头衔、群主/管理员标签。成员列表在打开群聊时按需读取，失败使用消息自身提供的信息。

显示时引号、反斜杠和换行进行代码转义，右键“复制消息原文”保留原文。历史和草稿分隔线由插件自动保护：误删注释、跨边界删除或全选删除时，自动恢复历史，只保留对草稿部分的有效编辑。发送只读取草稿分隔线以下的内容，Ctrl+S 仅保存草稿。通常不需要手动重建；`QQ: 重建聊天文档` 仍作为恢复入口保留。可在编辑器菜单取消回复。

## 自动跟随

`msg` 字段末尾的 `[回复]` 可按 VS Code 的链接手势（通常 Ctrl+单击）打开，也可以悬浮正文点击“回复这条消息”、右键回复或按 Ctrl+Shift+R。草稿上方显示回复对象和内容摘要；发送时携带 QQ 引用，可在编辑器菜单取消回复。

按 Enter 后，消息立即进入记录并清空输入区，发送情况标在这条消息的结束花括号后：等待发送、发送中、已发送、发送失败或结果未确认。可以立即继续输入下一条，后台按会话顺序发送。图片直接使用本地附件预览，不必等待上传回执。成功回执合并到原消息，不产生重复记录；失败内容留在原位置，通过 `[重试]` 单独重发，不覆盖新草稿。断线或超时的结果不确定，重试前会提示检查记录。重新加载窗口后，未完成的发送标为结果未确认，不自动重发。

聊天标签显示普通未读数量，`@` 表示有人提及自己，`↩` 表示有人回复自己，同时发生时优先显示 `@`，悬浮标签可查看详情。收到消息和自动置底不会直接清除未读；在底部实际操作聊天、主动打开会话或标记已读后清除。标签标记遵循 VS Code 的编辑器标签装饰设置。

打开会话、发送成功时自动置底。在底部阅读或输入时，新消息到达继续置底，保留草稿和选区。手动上翻后暂停跟随，状态栏显示“↓ 新消息 · N 条”；点击后回到草稿区并恢复跟随。加载更早历史时保持阅读位置。

## 配置与缓存

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `qq.wsUrl` | `ws://127.0.0.1:3001` | OneBot v11 正向 WebSocket 地址 |
| `qq.autoConnect` | `true` | 打开 QQ 视图后自动连接 |
| `qq.historyCount` | `50` | 初次读取历史数量 |
| `qq.messageLimit` | `500` | 每个会话显示与缓存上限，最高 2000 |

消息、草稿、收藏及媒体保存在插件的全局存储目录中，按登录账号隔离。默认运行于本机 UI 扩展宿主；打开 WSL / SSH 工程时，`127.0.0.1` 仍指运行桌面 VS Code 的机器。首次使用按收到的新消息统计本地未读；不与 QQ 手机端的已读状态同步，也不把历史列表全部计为新未读。

单张图片及一条消息的图片总大小上限为 16 MB，每条最多 8 个附件。图片缩略图按需缓存，媒体缓存按 128 MB / 7 天清理。发送失败保留草稿；发送超时或断线时可能无法判断服务器是否收到，应先查看记录，再决定是否重试。

“加载更多记录”逐步增加读取数量，受 NapCat 可提供的历史及消息上限限制。个别会话无历史或历史 API 失败时保留本地记录；语音、视频、文件及转发消息在本版显示文字占位。

## 开发与验证

```sh
npm install
npm run build
npm test
npm run test:extension
npm run package
```

F5 可启动扩展开发窗口。`test:extension` 使用独立 VS Code 配置及模拟 NapCat，验证原生文档、悬浮、图片预览、收发、回复、表情和草稿。

实际 NapCat 的只读验证：

```sh
node dist/test/live.cjs "path/to/tuiqq/config.json"
```

该脚本不发送消息，结果写入 `.test-output/live-result.json`。实际对外发送需在输入区由用户操作。稳定的远程任务定义见 `scripts/remote-tasks.json`。

打包产物：`artifacts/vscode-qq-0.1.9.vsix`。Windows 安装命令：`node scripts/install-extension.cjs`。

## 连接设置页面

点击 QQ 列表或收藏标题栏的齿轮，或运行 `QQ: 连接设置`。页面提供 WebSocket 地址、Token、自动连接、测试连接、仅保存、保存并连接和导入 tuiqq 配置。Token 保存在 VS Code 安全存储中，留空保持已保存的值，勾选清除可移除。测试连接只验证 NapCat 登录信息，不改变现有连接，也不保存表单。

侧栏同时显示上下两个可折叠列表：上方“列表”，下方“收藏”。“列表”合并群聊和好友，两个列表均按有效未读置顶、最近消息时间排序，并保留各自的搜索条件。免打扰普通消息不置顶，@我和回复我仍按例外提醒。
